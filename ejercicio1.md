**Punto 7 - ¿Que tipo de merge se realizo con experimento1?**
Se realizo un merge de tipo **3-way merge** (merge con commit de fusion), ya que experimento1 partio del Commit 1 y main tenia el Commit 2, por lo que las dos ramas habian divergido y Git tuvo que crear un commit de fusion.

**Punto 8 - ¿Que tipo de merge se realizo con experimento2?**
